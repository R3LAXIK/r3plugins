# R3ŁAXIK INC. — сайт

Статический сайт на чистом HTML/CSS/JS (без сборки и зависимостей).

## Структура

```
index.html          — разметка, один SPA-файл с hash-роутингом (#/, #/glowing-lite, #/glowing-pro, #/graph)
css/style.css        — все стили, включая три темы (Aqua, Liquid Glass, Flat)
js/script.js         — роутинг между страницами, пасхалка (5 кликов по лого) и переключатель тем
assets/img/          — логотип и скриншоты плагинов
assets/fonts/        — шрифт TT Travels Next (Medium/Bold)
```

## Запуск

Просто открой `index.html` в браузере — сборка не нужна.
Для GitHub Pages: включи Pages для ветки/папки с этим содержимым, `index.html` в корне подхватится автоматически.

## Пасхалка

5 кликов по логотипу за ~1.5 секунды открывают окно «ROAD TO THE 500!» и разблокируют
переключатель тем (Aqua / Liquid Glass / Flat) внизу справа. Выбор темы и факт
разблокировки сохраняются в localStorage браузера.
